# Building the Workout App APK

This folder is the native Android project generated by Capacitor.

## Prerequisites (Fedora)

```bash
# Node 22+
node -v; npm -v

# JDK 21+ — Capacitor 7 needs 21. On Fedora java-21-openjdk is currently empty,
# use java-25-openjdk (or any 21+):
sudo dnf install java-25-openjdk
java -version # should be 21+

# Android SDK — via Android Studio or Command Line Tools:
# If you used the terminal approach:
ls ~/Android/Sdk # should contain build-tools/ platform-tools/ platforms/ cmdline-tools/
```

Set env vars:

**bash** (add to `~/.bashrc`):
```bash
export JAVA_HOME=/usr/lib/jvm/java-25-openjdk
export ANDROID_HOME=$HOME/Android/Sdk
export PATH=$PATH:$ANDROID_HOME/cmdline-tools/latest/bin:$ANDROID_HOME/platform-tools
```

**fish** (add to `~/.config/fish/config.fish`):
```fish
set -x JAVA_HOME /usr/lib/jvm/java-25-openjdk
set -x ANDROID_HOME $HOME/Android/Sdk
fish_add_path $ANDROID_HOME/cmdline-tools/latest/bin
fish_add_path $ANDROID_HOME/platform-tools
# then restart fish or: source ~/.config/fish/config.fish
```

If Gradle complains `SDK location not found`, ensure this file exists:

```
android/local.properties
  sdk.dir=/home/fillipe/Android/Sdk
```

Create it with:

```bash
# bash
echo "sdk.dir=$ANDROID_HOME" > android/local.properties
# fish
echo "sdk.dir=$ANDROID_HOME" > android/local.properties
```

And accept licenses once:

```bash
# bash / fish (sdkmanager is on PATH after the exports above)
yes | sdkmanager --licenses
```

## Build steps (run from project root `Workout app/`)

```bash
npm run build              # vite → dist/
npx cap sync android       # copy web assets to android/app/src/main/assets/
cd android
./gradlew assembleDebug
```

APK output:

```
android/app/build/outputs/apk/debug/app-debug.apk
```

For a signed release (Play Store):

```bash
./gradlew assembleRelease
# configure signingConfig in android/app/build.gradle first
```

Open in Android Studio alternative: `npx cap open android` → `Build > Build APK(s)`.

## Installing the APK on a phone

**Yes — you can just copy the `app-debug.apk` to the phone and tap it.**

* Via USB: copy the file to `Downloads/`
* Via Drive/Email/Telegram: download on the phone

On first install Android will ask to **Allow install from unknown sources** (or *Allow from this source* for your file manager / browser) — allow it, then tap `Install`.

Or via `android-tools` (`adb`) with USB debugging enabled:

```bash
adb devices              # check phone is connected
adb install android/app/build/outputs/apk/debug/app-debug.apk
# update: adb install -r ...  (reinstall)
```

The debug APK is not signed for the Play Store but is fine for personal sideloading.
