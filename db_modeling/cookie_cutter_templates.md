# Cookie-cutter Workout templates

This page describes existing and popular programs that may come pre-made so users won't have to always create their own.

The idea is that, if a given workout program is to be implemented, it will also create all the required exercises for it and group its workouts under a program. If the exercise already exists with this name, skip it.

## Reddit PPL

### Description

A popular push/pull/legs workout from Reddit.

See more at https://www.reddit.com/r/Fitness/comments/37ylk5/a_linear_progression_based_ppl_program_for/

### Exercises

- Bench press
- Overhead press
- Incline dumbbell bench press
- Triceps pushdown
- Overhead triceps extension
- Dumbbell lateral raise
- Deadlift
- Lat pulldown
- Seated cable row
- Face pull
- Hammer curl
- Dumbbell curl
- Squat
- Romanian deadlift
- Leg press
- Seated leg curl
- Standing calf raise

### Workout plans

Where the program lists alternatives, the **first option** is used (e.g. "Deadlifts / Barbell rows" → deadlift). AMRAP sets are counted as regular working sets.

- Reddit PPL Push:
    - Bench press, 5 working sets (4×5 + AMRAP)
    - Overhead press, 3 working sets
    - Incline dumbbell bench press, 3 working sets
    - Triceps pushdown, 3 working sets
    - Overhead triceps extension, 3 working sets
    - Dumbbell lateral raise, 6 working sets
- Reddit PPL Pull:
    - Deadlift, 1 working set (AMRAP)
    - Lat pulldown, 3 working sets
    - Seated cable row, 3 working sets
    - Face pull, 5 working sets
    - Hammer curl, 4 working sets
    - Dumbbell curl, 4 working sets
- Reddit PPL Legs:
    - Squat, 3 working sets (2×5 + AMRAP)
    - Romanian deadlift, 3 working sets
    - Leg press, 3 working sets
    - Seated leg curl, 3 working sets
    - Standing calf raise, 5 working sets

The program alternates the main lift between sessions (bench/overhead press, deadlift/barbell row); only the first option is included. Duplicate a plan and swap the lift if you want the alternate day.

## GZCLP

### Description

Linear progression variant of the GZCL method: one heavy T1 lift, one T2 compound and one T3 accessory per day.

See more at https://liftvault.com/programs/powerlifting/gzclp-program-spreadsheets/.

### Exercises

- Squat
- Bench press
- Overhead press
- Deadlift
- Barbell row
- Lat pulldown

### Workout plans

Rep schemes change over the weeks (T1 5×3 → 6×2 → 10×1, T2 3×10, T3 3×15+); only the number of sets is encoded.

- GZCLP A1:
    - Squat (T1), 5 working sets
    - Bench press (T2), 3 working sets
    - Lat pulldown (T3), 3 working sets
- GZCLP B1:
    - Overhead press (T1), 5 working sets
    - Deadlift (T2), 3 working sets
    - Barbell row (T3), 3 working sets
- GZCLP A2:
    - Bench press (T1), 5 working sets
    - Squat (T2), 3 working sets
    - Lat pulldown (T3), 3 working sets
- GZCLP B2:
    - Deadlift (T1), 5 working sets
    - Overhead press (T2), 3 working sets
    - Barbell row (T3), 3 working sets

## Reddit Basic Beginner Routine

### Description

Reddit's r/fitness full-body, barbell based beginner's routine.

See more at https://thefitness.wiki/routines/r-fitness-basic-beginner-routine/

### Exercises

- Barbell row
- Bench press
- Squat
- Chin-up
- Overhead press
- Deadlift

### Workout plans

Every lift is 3×5+, with the last set being AMRAP (not modelled; 3 working sets are encoded). Alternate A and B, resting a day between sessions.

- Basic Beginner A:
    - Barbell row, 3 working sets
    - Bench press, 3 working sets
    - Squat, 3 working sets
- Basic Beginner B:
    - Chin-up, 3 working sets (first option chosen for "chin-ups or equivalent")
    - Overhead press, 3 working sets
    - Deadlift, 3 working sets

## Template conventions (as implemented)

- Workout programs group related workouts (e.g. "Stronglifts 5×5" contains Workout A and B). Workouts can also exist without a program (standalone) — deleting a program detaches its workouts instead of deleting them.
- Installing a template creates a single program containing all of its workouts; exercises are reused by name.
- Exercise names live in a single shared catalog: `src/templates/exercises.js`. Templates only reference those entries, so the same movement always has the same name and is reused across templates when installed.
- Names use sentence case: only the first letter is capitalised (acronyms/proper nouns aside), e.g. `Barbell row`, `One-arm dumbbell row`.
- Where a program offers alternatives, the first option is used. The user can swap or add exercises in the installed plan.
- Set counts are the lower bound of any range (e.g. 3-4 → 3). AMRAP sets count as a normal set. Rep ranges are not modelled — reps are entered per set when training.
- Warm-up defaults: 3 for heavy barbell compounds (4 for deadlift), 1 for secondary/machine compounds, 0 for isolation work. Programs that specify warm-ups override this.
- Installed plans are normal user-owned copies (`source = template`, with `templateKey`/`templateVersion` provenance); editing them never touches the catalog.
